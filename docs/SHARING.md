# 项目介绍与演示示例

以下文字可用于介绍项目。请按实际使用体验调整，不承诺资料完整、史料审校完成或搜索排名。

## 一句话介绍

荷马史诗脉络图是从阅读路书 ReadMap 独立开源的人物地图：搜索神祇与英雄，在家族谱系和特洛伊战争阵营之间切换，辅助阅读《伊利亚特》《奥德赛》。

## 简短介绍文案

读荷马史诗时遇到陌生的人物名字，可以打开这张地图，从一位人物的简介与亲属关系读起，再切换谱系或阵营视图。当前公开快照包含 208 位人物、9 个类别、328 条关系，支持中文、外文名、拼音和首字母搜索，无需数据库、账号或 API key。

- [在线体验](https://homeric-epic.inklinks.io/)
- [GitHub 源码与贡献](https://github.com/adonisly/homeric-epic-map)
- [阅读路书 ReadMap：更多阅读路径与知识图谱](https://readmap.inklinks.io/)

图谱结合史诗和通行神话，关系存在异说；公开版不包含现代译本整份专名索引原文。欢迎附来源纠错。

## 三个演示起点

1. [宙斯家系](https://homeric-epic.inklinks.io/?view=tree&mode=ego&focus=zeus)：从神祇与家族谱系出发，切换人物焦点。
2. [阿基琉斯](https://homeric-epic.inklinks.io/?view=tree&mode=ego&focus=achilles&figure=achilles)：查看人物与亲属，继续进入战争阵营图。
3. [奥德修斯](https://homeric-epic.inklinks.io/?view=tree&mode=ego&focus=odysseus&figure=odysseus)：演示搜索、详情和「分享此人物」。
