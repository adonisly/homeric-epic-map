# 操作演示

`assets/demo.mp4` 是独立运行页面的真实浏览器交互录制，约 21 秒、1280×816、20 fps、无音轨。720px 高的实际页面下方增加独立中文字幕区，不遮挡人物卡片。`assets/demo.gif` 为前 15 秒低帧率预览；`overview.jpg` 与 `demo-poster.jpg` 为实际阵营图截图。

录制日期：2026-11-16。快照：208 位人物、9 个类别、328 条关系。

演示顺序：

1. 默认打开宙斯人物谱系。
2. 输入 `adxs`，在建议中找到奥德修斯。
3. 定位人物并打开详情，查看简介与亲属关系。
4. 关闭详情，切换全景谱系。
5. 切换阵营关系图。
6. 点击分享，生成能恢复当前视图的链接。

画面为实际数据与界面，不包含现代译本专名索引、账号页面或数据库管理界面。浏览器自带的焦点与滚动动画予以保留。演示是功能说明，不替代史料审核。

后续窄屏优化将阵营图例改为默认折叠；展开后可查看录制中的完整图例。交互步骤不变。
