# 公开数据说明

本快照来自 ReadMap 的公开人物图谱，采用字段白名单导出：

- `figures`：稳定 ID、中英文与罗马名、别名、性别、类别、战争立场、分组、代际、神职、称号、整理简介、异说与标签。
- `factions`：类别名称、配色、排序、图例标记。
- `relations`：稳定 ID、关系起点 `from_figure_id`、终点 `to_figure_id`、类型、整理说明及异说。
- `relationTypes`：关系名称、配色和方向性。
- `nameIndex`：空数组。保留核心兼容接口，不分发现代译本整份专名索引；静态人物目录由 `figures` 生成。

`parent` 为父母指向子女；配偶、兄弟姐妹关系无方向，战争、爱慕等关系按 `relationTypes.is_directional` 解释。亲属图中的母亲／父亲等称谓由人物性别与关系确定。`standard` 是本图采用的整理口径，不表示不存在其他神话版本；`variant`／`disputed` 和异说说明应随资料保留。

所有 `image_url` 为 null，未审核的图片不发布。没有账号、评论、编辑历史、真实热搜、凭据或生产写入接口。英文名与中文译名用于识别人名，不主张对事实或名称的专有权；原创整理表达按项目许可，引用作品保留适用权利。

人物和关系经通行神话及史诗整理，覆盖《伊利亚特》《奥德赛》及辅助谱系，不是任何现代译本附录的再发布。仍需持续做来源校订，当前结构检查不等于逐条史料审核。建议核对荷马原文与古代资料，如 [Perseus《伊利亚特》](https://www.perseus.tufts.edu/hopper/text?doc=Perseus%3Atext%3A1999.01.0133)、[Perseus《奥德赛》](https://www.perseus.tufts.edu/hopper/text?doc=Perseus%3Atext%3A1999.01.0135)。这些是阅读参考，不宣称每条记录已逐项对应其中一节，也不将网站上的译文自动视为可复制材料。

导出时按表分页并核对计数，但不是跨表事务；发布前需复核两次导出是否一致并检查关系端点。`snapshot-info.json` 保存导出时间与校验值，用于完整性追溯。生产库不接受本文件整表覆盖。
